# Support

[Version française](SUPPORT.fr.md)

Start with the [getting started guide](docs/docs/getting-started.md), [API architecture](docs/docs/architecture.md), and [testing guide](docs/docs/testing.md). Search [existing issues](https://github.com/Graphiks-org/WebGPU/issues) before opening a new one. For a usage question or bug, [open an issue](https://github.com/Graphiks-org/WebGPU/issues/new/choose) with your platform, dependency version, expected behavior, and a minimal reproduction.

Please use the [private security route](SECURITY.md) for vulnerabilities. Community support is best effort; there is no guaranteed response time.
