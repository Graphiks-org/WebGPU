# Politique de sécurité

[English version](SECURITY.md)

Signalez les vulnérabilités présumées en privé avec le [formulaire de signalement GitHub](https://github.com/Graphiks-org/WebGPU/security/advisories/new). Indiquez les versions ou commits concernés, les étapes de reproduction et l'impact possible. Ne publiez pas les détails d'exploitation dans une issue publique. Les responsables accuseront réception et coordonneront avec vous le correctif et sa divulgation.

Pour les bugs ordinaires ou les questions d'utilisation, utilisez [GitHub Issues](https://github.com/Graphiks-org/WebGPU/issues) ou la page [Support](SUPPORT.fr.md). Le projet est en incubation ; aucune durée de prise en charge ni délai de réponse précis n'est garanti.
