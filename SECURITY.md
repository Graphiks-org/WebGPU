# Security policy

[Version française](SECURITY.fr.md)

Please report suspected vulnerabilities privately through [GitHub's vulnerability reporting form](https://github.com/Graphiks-org/WebGPU/security/advisories/new). Include affected versions or commits, reproduction steps, and the potential impact. Do not disclose exploit details in a public issue. Maintainers will acknowledge the report and coordinate a fix and disclosure with you.

For ordinary bugs or usage questions, use [GitHub Issues](https://github.com/Graphiks-org/WebGPU/issues) or [Support](SUPPORT.md). This project is incubating; no specific security support window or response deadline is promised.
