# Code of Conduct

[Version française](CODE_OF_CONDUCT.fr.md)

We welcome constructive participation from everyone. Be respectful, assume good faith, and focus criticism on ideas and code. Harassment, discriminatory language, personal attacks, and publishing another person's private information are unacceptable.

This code applies to repository discussions, issues, pull requests, and other project spaces. Maintainers may edit or remove harmful content and limit participation when needed. Report conduct concerns privately to the maintainers through a GitHub account message when available, or ask for a private contact route in an issue without disclosing sensitive details. Reports will be handled with care; maintainers will consider the context and explain any action they can share.
