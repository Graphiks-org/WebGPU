# Code de conduite

[English version](CODE_OF_CONDUCT.md)

Nous accueillons toute participation constructive. Respectez les autres, présumez leur bonne foi et critiquez les idées et le code plutôt que les personnes. Le harcèlement, les propos discriminatoires, les attaques personnelles et la divulgation d'informations privées sont interdits.

Ce code s'applique aux discussions, issues, pull requests et autres espaces du projet. Les responsables peuvent modifier ou retirer les contenus nuisibles et limiter la participation si nécessaire. Pour signaler un problème de conduite, contactez un responsable en privé via GitHub si possible, ou demandez un canal privé dans une issue sans révéler de détails sensibles. Les signalements seront traités avec soin ; les responsables tiendront compte du contexte et expliqueront les mesures qu'ils peuvent partager.
